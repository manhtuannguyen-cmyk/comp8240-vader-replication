# Third-party notices and dataset scope

VADER code and lexicon are attributed to C. J. Hutto and Eric Gilbert. The unchanged upstream licence is in `data/original_vader/LICENSE.txt`; the historical code's attribution notice is retained in the compatibility adaptation. The original Python 2 source is also preserved. Compatibility changes are syntax, source path and Latin-1 lexicon decoding; sentiment rules/valences are not edited.

GoEmotions is attributed to Demszky et al. (2020) and Google Research. The released licence is preserved in `data/goemotions/raw/LICENSE`. The three-class mapping is a project-specific derivative; original emotion annotations and official split membership remain available.

Benchmark snippets have third-party origins. The public export retains source/rights notices and retrieves the authors' exact pinned text release rather than automatically republishing those text files. The repository licence must not be interpreted as independent clearance of every third-party text source.

YouTube comments, annotations, provider responses and text-bearing outputs are not licensed for unrestricted redistribution by this project. They remain private, with source-specific lifecycle and access documentation. No root licence purporting to grant rights to those data has been added.
