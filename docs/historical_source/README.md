# Historical implementation lineage

These are faithful source snapshots from the working project before repository consolidation. They retain their old paths/imports for audit and are not the portable entry points.

Use the commands in the main README to execute the ported scripts under `src/`. Historical selection and replacement algorithms are reproduced and checked against the archived sample/audit by `src/data_processing/sample_youtube.py`. The original SQLite editing script is kept only as provenance and must not be run against completed annotations.
